# Marketing Super Team (reference personas)

Six advisory persona files, added 2026-06-04 from the "Marketing Super Team" upload.
An advisory board of five marketing experts plus an index that runs them together.

- ai-super-team.md: the board runner. Runs all five at once on a business question.
- alex-hormozi-offer-architect.md: offers, pricing, value stacks, lead magnets.
- david-ogilvy-copy-chief.md: research-first copy, headlines, the big idea.
- gary-vaynerchuk-content-strategist.md: content volume, platform-native distribution.
- russell-brunson-funnel-architect.md: funnels, value ladder, story selling.
- sabri-suby-lead-gen-strategist.md: lead-gen economics, HVCO, retargeting.

## Status and how to use

These are stored as reference, not wired as active skills or agents. They sit in
context/ so a strategist can draw on the frameworks, the same way the engine draws on
other context. They are not part of the funnel swarm or the stream-ownership model.

To make the board invokable as a skill (for example "run the super team"), it would move
to skills/marketing-super-team/ with the index as SKILL.md. That is a deliberate
behavior change, so it is left for a decision rather than assumed.

## Notes before any engine or customer-facing use

- Raw external content, kept as-is. The files contain em dashes and impersonate real
  named people, neither of which fits the engine's house rules. Treat them as raw
  reference. Anything they help produce still goes through the normal authoring path and
  the quality gates (arabic-copy-qa or english-copy-qa, brand-qa-reviewer,
  compliance-privacy-check) before it becomes customer-facing.
- Their advice is generic and English-first. The brand is Arabic-first with the Thmanyah
  tone, so their output is an input to strategy, not finished copy.
