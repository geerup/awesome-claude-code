This is the original Maharat Marketing Engine's fact layer, preserved in full when the engine
was adapted into a personal brand and career engine. Nothing was thrown out: files were moved
here, not deleted.

Do not edit these as if they were the active brand. The active profile is `me`
(see `context/active-profile.md`). Read this profile to borrow patterns, study a worked
example, or restore Maharat as the active profile.
