# outputs/

Generated artifacts per campaign land here, one subfolder per campaign_id (the brief
filename). For example `outputs/2026-06-nonpayer-email/`.

What goes here: the assembled approval-ready packages, the QA results, the final artifacts a
run produces. Nothing here is sent or published. These are the deliverables the human gate
reviews and the record of what a run produced.

Nothing in this folder sends, publishes, or spends. No em dashes, Western numerals,
Arabic-first.
