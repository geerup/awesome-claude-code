## How to read this file

Variants are organized by channel. Each variant has an id, segment, all copy slots, one CTA,
language en. Subject lines for email include a primary flag. Fills map each variant to the
relevant asset-brief copy slots.

No em dashes anywhere. Western numerals only. One clear CTA per asset. No invented price,
promo, Skill Path title, or instructor claim beyond cleared public facts. No accreditation.
