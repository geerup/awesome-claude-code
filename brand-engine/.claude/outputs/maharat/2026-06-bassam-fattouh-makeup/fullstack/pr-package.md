## 3. Press Release Brief

This brief is the instruction to copywriter-ar (Arabic, primary) and copywriter-en (English variant).
It is not the press release itself. The copywriters draft from this brief. The drafts then run
arabic-copy-qa (AR) and english-copy-qa (EN), then brand-qa, before advancing.

### Brief to copywriter-ar and copywriter-en

**Campaign:** 2026-06-bassam-fattouh-makeup

**Language:** Arabic primary (copywriter-ar). English variant (copywriter-en). Arabic is not a
translation of English. It is the primary text and must read naturally in Modern Standard Arabic
with Gulf-familiar wording.

**Format:** Press release. Headline, subhead, dateline, two to three body paragraphs, boilerplate,
contact line. No em dashes anywhere. Western numerals only. No tatweel or kashida in Arabic. RTL-correct.

**Tone:** Thmanyah benchmark. Plain, confident, empowering. The learner is gaining a skill, not
fixing a gap. Short sentences. Active voice. No hype words, no over-explanation.

**Headline direction (Arabic):**
Lead with the name of the instructor and the arrival of the class on Maharat. The headline states
the fact: Bassam Fattouh has launched a makeup Masterclass on Maharat, and the first chapter is
free. Do not write a benefit-statement headline; write the fact. One sentence. No em dash.

Example direction (not final copy): "بسام فتوح يطلق كلاس مكياج شامل على منصة مهارات والدرس الأول مجاني"

**Headline direction (English):**
Same fact. Name, platform, free first chapter. One sentence.

Example direction (not final copy): "Bassam Fattouh Launches Makeup Masterclass on Maharat, First Chapter Free"

**Body guidance:**

Paragraph 1 (news peg): State the fact of the class launch. Name the instructor using the cleared
name (Bassam Fattouh / بسام فتوح). State the class title. State the platform (Maharat). State
that the first chapter is free. State the chapter count (20 chapters). Do not invent anything
beyond these confirmed facts.

Paragraph 2 (what the learner gets): Name specific, confirmed lessons from the live class page.
Use at minimum: Foundation 101, The Smokey Eyes, The Day to Night, The Color Glam, The Graphic
Metallic Look. These names are confirmed from the live page and may be used verbatim. Frame as
what the learner can create and do, not what they lack. Empowering, never deficit-framed.

Paragraph 3 (access): State access via a Maharat subscription, price reference only (under $7
per month billed annually, exact as the public page states it). Direct readers to the class page
URL. No promotion unless Ahmed confirms one; omit any promo language if none is confirmed. No
accreditation reference.

**Do not include:**
- Any promotion, discount, or trial (ASSUMPTION, not confirmed)
- Any accreditation claim or implication
- Any unannounced Maharat features, roadmap, or plans
- Any invented lesson names beyond those confirmed from the live page
- Any generated imagery brief; imagery is an open item pending rights-cleared assets

**Boilerplate (to be adapted by copywriter, facts only):**
Maharat is an Arabic-first self-development platform for the Arab world. It publishes Masterclasses
from regional experts and offers subscription plans starting at under $7 per month billed annually.
The platform serves Arabic-speaking adults across the GCC and wider Arab world.

No accreditation language. No fundraising language. No roadmap.

**Contact line:** To be completed by Ahmed or the PR lead with the approved media contact name and
email before distribution. Copywriters write "[MEDIA CONTACT NAME], [MEDIA CONTACT EMAIL]" as
a placeholder.

**QA gate after drafting:**
Arabic draft: arabic-copy-qa first, then brand-qa. English draft: english-copy-qa first, then brand-qa.
Both must pass before the press release advances to the pr-package as a confirmed asset. A fail at
either gate is a hard stop back to the copywriter with exact fixes.
