## Binding rules applied (length adaptation only, no new claims)

1. The bound AR text is taken from the QA-passed source variant named in each slot's SOURCE line.
2. Display slots (headlines, field headlines, theme labels, CTA chips) get a length-adapted
   lockup of the source line when the full source sentence is too long for the slot's type size
   and safe area. The lockup is a true subset or a faithful condensation of the same QA-passed
   copy, carrying the same meaning, the same framing, and no word the source did not already use.
   Where the source already fits (most CTAs, subject lines, push titles), it is bound verbatim.
3. Body and subline slots get the source line verbatim or a two-line break of the source body,
   no rewording.
4. No price, no promo, no plan length, no chapter count, no lesson title, no quote is added.
5. Instructor naming: the seven nameable carry confirm-at-gate, cleared page-sourced facts only.
   The four non-nameable (Rahma Riad, Sami Al Jaber, Mona Ataya, Mo Islam) never appear and live
   only inside "والمزيد عبر مجالات عديدة". Verify-before-public-use facts excluded for Toufic
   Kreidieh (no Brands For Less, no $10,000-garage detail) and Elda Choucair (no Omnicom, Forbes,
   Cannes, no 900-plus or 1000-plus figures).
6. Every ar slot is RTL, right-anchored to the right safe-area boundary defined in design-specs.md.
