## How to read this file

For each generatable asset brief, this file records:
- The asset brief identifier and its design-spec equivalent
- Every [en ...] overlay slot from the brief, in the order they appear in the layer stack
- The bound EN text for each slot
- The source variant id from copy-package.en.md or additional-copy.en.md
- An LTR and safe-area placement note for the compositor

All text is LTR. All text is overlay-only: nothing is baked into the generated image layer.
The designer applies these text layers at build time as named overlay layers above the
text-free generated image export. English copy is left-anchored (X 80 on 1080px canvases,
X 160 on 1920px canvases, X 240 on email crops) per the design-specs.md global slot
definitions.

Instructor-naming discipline: 7 nameable instructors are confirm-at-gate. 4 non-nameable
instructors (Rahma Riad, Sami Al Jaber, Mona Ataya, Mo Islam) never appear in any slot.
Toufic Kreidieh and Elda Choucair carry additional verify-before-public-use restrictions
noted per slot.
