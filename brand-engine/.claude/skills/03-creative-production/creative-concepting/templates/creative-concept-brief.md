# Creative concept brief template

One block per concept. 2 to 4 concepts per strategy angle. Each rationale names the angle it
serves. All example text is illustrative only. Replace it. Do not invent Skill Path titles,
instructor names, offers, or prices.

## Concept block

```
id:            concept-<angle-slug>-<n>      # e.g. concept-growth-1
serves_angle:  <the strategy-artifact angle this concept expresses>
segment:       <strategy-artifact segment name>
description:   <one or two lines of visual direction, text-free image intent>
rationale:     <one line: why this concept serves that angle for that segment>
channel:       paid | lifecycle | organic
```

## Illustrative example (replace before use)

```
id:            concept-example-1
serves_angle:  example-angle
segment:       example-segment
description:   A calm workspace at dawn, warm light, one focused person, generous space.
               Text-free. Emerald accent as a single highlight, near-black ground.
rationale:     Frames steady daily progress, matching the example angle for this segment.
channel:       lifecycle
```

## Channel routing summary

```
paid:       <concept ids routed to paid feeds>
lifecycle:  <concept ids routed to lifecycle email or messaging>
organic:    <concept ids routed to organic social>
```

## Checklist before handoff

- 2 to 4 concepts per angle. Each rationale names the angle it serves.
- Each concept routed to paid, lifecycle, or organic, matching the channel_plan.
- Empowering, never deficit-framed. No accreditation implication.
- No invented titles, names, offers, or prices. Missing means stop and ask.
- No em dash, no tatweel, Western numerals only.
