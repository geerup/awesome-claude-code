# Announcement Plan

Internal plan. Owned by pr-comms. Feeds the pr-package. Rules on what is sayable; it never
writes the release and never distributes. The guardrail_check is the gate any announcement
passes before a release or outreach advances. Distribution is a human-gate action.

## News hook (why this is news now)

One line, drawn only from the sayable set: the real milestone, launch, or data point that
makes this news now. Keep it honest and inside the boundary. No forced newsjacking, no invented
moment.

- news_hook:
- hook strength: strong | weak (flag weak when there is no genuine hook, even if the
  announcement is otherwise sayable)

## Spokesperson and quote

- approved spokesperson: (from the brief; do not attribute an unconfirmed quote)
- quote approval: OPEN ITEM until confirmed

## Guardrail check

- result: pass | fail
- on fail: { check, span (quoted offending text), fix }

Pass only if the proposed announcement draws solely from the sayable set and nothing from the
hold-out set leaks in. A single hold-out leak is a fail.

## Open items

- Anything unresolved (fact not yet public, spokesperson not confirmed, quote not approved,
  held-out item that the campaign wants and must wait on).
