# Web experience direction

Fills the direction fields of the `web-design-package`. Sets the architecture, the flow, the
wireframes, and the visual direction. No copy here: slots are labeled by language and left empty.

## Envelope reference

```
campaign_id   <from the active brief filename>
produced_by   web-design-director
stream        6 conversion path (web design)
status        draft | qa-passed | gated-pending | approved
qa            { skill_eval: , brand_qa: }
brief_refs    <offer, gate type, page direction the brief states>
```

## Information architecture

| # | Page or section | The job (one line) |
|---|---|---|
| 1 | Hero | state the offer and the one primary action |
| 2 | <section> | <what it must accomplish toward the conversion> |
| 3 | Signup section | the one primary action, into the gate |

Sections beyond what the offer needs are cut. Each must earn its place against the conversion.

## UX flow

```
ad or organic click -> page (first view) -> primary action -> signup gate (open)
  -> submitted -> confirmed -> lifecycle entry
states to design: first view, gate open, submitted, confirmed, error
```

## Visual direction

- How the brand constants apply to the web surface: background #141414, card surfaces #1A1A1A,
  emerald #009975 as a highlight, generous space, premium and uncluttered.
- Imagery direction: text-free. No Arabic baked into any planned image.

- No copy written here. Slots labeled by language and left empty for stream 4.

- RTL reading order. Western numerals. No em dashes, no tatweel.
