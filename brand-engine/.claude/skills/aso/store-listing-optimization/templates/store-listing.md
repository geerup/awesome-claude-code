## App Store fields

| Field | Limit | Arabic (primary) | English | Keyword targets served |
|---|---|---|---|---|
| Title | about 30 chars |  |  |  |
| Subtitle | about 30 chars |  |  |  |
| Keyword field | about 100 chars |  |  |  |
| Description | long |  |  |  |

The keyword field is comma separated with no wasted spaces. No Apple-indexed stop words ("app,"
"the" and their Arabic equivalents). No word repeated across the title, subtitle, and keyword field.
Include only one of a singular or plural form, and rely on Apple combining single words across
fields into search phrases. Western numerals only.

If Custom Product Pages are planned (see the creative skill), each CPP can carry its own assigned
keyword set mapped to the segment it serves, following the same mechanics. Per-CPP keywords are a
gated publish.
