# Editorial calendar template

One row per content item. Every theme maps to the strategy angle and an SEO cluster. All
example values are illustrative only. Replace them. Do not invent offers, prices, Skill Path
titles, or instructor names to justify a theme. If a theme needs one and the brief is silent,
stop and ask. Western numerals only, no em dash, no tatweel.

## Calendar item

```
theme:         <short content theme>
angle_link:    <how this theme serves the strategy angle>
seo_cluster:   <the keyword_map cluster this theme targets>
primary_query_ar: <main Arabic query, RTL>
primary_query_en: <main English query>
format:        article | guide | listicle | how-to
target_date:   <YYYY-MM-DD>
owner:         <named owner>
status:        planned | briefed | in-progress | published
```

## Cadence

```
cadence:       <e.g. 2 articles per week> , <why this is realistic for the team>
```

## Illustrative example (replace before use)

```
theme:         building a daily learning habit
angle_link:    reinforces the one-step-a-day angle
seo_cluster:   learn-a-new-skill
primary_query_ar: كيف ابني عادة تعلم يومية
primary_query_en: how to build a daily learning habit
format:        how-to
target_date:   2026-06-10
owner:         content-marketer
status:        planned

cadence:       2 articles per week, matches current authoring capacity.
```

## Checklist before handoff

- Every theme maps to the angle and an SEO cluster. No orphan content.
- Each item has a format, a target date, an owner, and a status.
- Cadence is stated and realistic.
- English-first, English in parallel.
- No em dash, no tatweel, Western numerals only.
- No invented offer, price, Skill Path title, or instructor name. No accreditation implication.
- Empowering framing, never deficit-framed.
