# Content distribution plan template

One plan per source article. One source angle carried across every derivative. This skill
routes and briefs, the destination owners write the final copy. All example values are
illustrative only. Replace them. Do not invent offers, prices, Skill Path titles, or
instructor names. If a derivative needs one and the brief is silent, stop and ask. English-first,
English in parallel, Western numerals only, no em dash, no tatweel.

## Source

```
source:        <article_brief id or published URL>
core_angle:    <the spine every derivative keeps>
core_cta:      <the source article CTA>
```

## Derivatives

```
- format:        email | organic-social | other
  angle_carried: <the angle this format carries from the source>
  cta:           <the action for this format>
  owner:         lifecycle-architect + copywriter | organic-social | <other>
  language:      ar | en
  routing_notes: <what the owner needs to produce it>
```

## Sequence

```
sequence:      <order and timing of the derivatives around the article>
notes:         <channels unavailable, values blocked on the brief>
```

## Illustrative example (replace before use)

```
source:        article-daily-learning-habit
core_angle:    one step a day builds a skill that stays with you
core_cta:      ابدأ مسارك الأول

derivatives:
  - format:        email
    angle_carried: one small step beats a big plan you never start
    cta:           ابدأ اليوم
    owner:         lifecycle-architect + copywriter-ar
    language:      ar
    routing_notes: pair with a subject_lines set from the subject-lines sub-skill.
  - format:        organic-social
    angle_carried: a 3 line habit you can start today
    cta:           اقرأ المقال
    owner:         organic-social
    language:      ar
    routing_notes: 1 carousel plus 1 short caption, route to the signup gate.

sequence:      publish article, then email day 2, then social posts across week 1.
notes:         none
```

## Checklist before handoff

- One source angle carried across every derivative.
- Each derivative has a format, the angle, a CTA, an owner, and a language.
- Email routes to lifecycle and the copywriters, social routes to organic-social.
- Sequence and timing are stated.
- This plan routes and briefs, it does not write final copy.
- No em dash, no tatweel, Western numerals only.
- No invented offer, price, Skill Path title, or instructor name. No accreditation implication.
- No distribution tool adopted without approval.
