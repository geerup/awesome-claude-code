# portfolio-case-study-writer (v1)

Governed by M00. Used by: A13, A20. Calibrated replacement for the legacy skill (import_required in master.json.legacy_assets); legacy triggers are preserved on import.

## Purpose
Turn one documented body of work into a portfolio case study: problem, system built, decisions made, verified outcome, written to prove "builds the systems that run marketing" to a named audience.

## Method
1. Select the case from master.json content_source_material; the seven case study files are import_required, so until import, only the Maharat systems and Canonical organic facts are writable.
2. Fix one audience (recruiters, CMOs, founders, MENA operators) and one lane before drafting.
3. Structure: context, constraint, system design, governance, outcome. Numbers appear as proof inside the narrative, never as the headline.
4. For the Maharat cases, state the true state plainly: approval-ready and dev-handoff-ready; 21 agents, 4 swarm patterns, 73 skills as scope proof; the human-approval gate framed as judgment.
5. Close with what the reader can verify and what remains unproven. Name gaps unprompted.
6. Stage to the gate with the risk note; portfolio surface placement waits for the imported HTML files.

## Rules
- Every metric traces to data/master.json or it does not appear; no outcome is dramatized beyond its source field.
- No live performance figures for the Maharat systems: no ROAS, no revenue lift, no engagement rates.
- Canonical case uses 3M grown 3x organically and the exact scope line; GTM ownership is never implied.
- Pipeline language is always "influenced"; headcount stays out of every case.
- One case per study; no composite or blended narratives across roles.

## Eval cases

### E1
**Input:** Draft Maharat case ends with "the engine lifted qualified leads 25% in month one".
**Expected:** Flagged; figure removed as untraceable and impossible at approval-ready state; closing rebuilt on scope-and-outcome language.
**Fail if:** The 25% figure or any live outcome survives.

### E2
**Input:** Draft blends Canonical community growth and Mindvalley work into one "organic growth" case.
**Expected:** Split or narrowed to one role's documented facts; Mindvalley content held pending import.
**Fail if:** A blended case ships or import_required material is paraphrased into claims.

### E3
**Input:** Draft honesty section omits that the Maharat systems have not run live.
**Expected:** The true state is stated in the case body; candor over diplomacy.
**Fail if:** The reader could conclude the system is in production.

### E4
**Input:** Draft headline leads with "10M+ audience built at Canonical".
**Expected:** Corrected; 10M+ is career combined only, and numbers never serve as the headline.
**Fail if:** The misattributed figure or number-led headline survives.
