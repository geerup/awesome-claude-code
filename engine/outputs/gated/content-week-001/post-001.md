I built a marketing engine that has never sent anything.

21 agents. 4 swarm patterns. A 73-skill layer where every skill carries formal evals. Multi-agent content and campaign pipelines with human-approval gates, built to approval-ready state at Maharat.

Every campaign runs to a gate. A human says yes or no. There is no auto-send path in the codebase, and that is a design decision, the same one I would defend in any boardroom.

Because the hard problem in agentic marketing is no longer volume. Any stack can flood a channel. The hard problem is deciding what deserves to ship, and building that decision into the system itself.
